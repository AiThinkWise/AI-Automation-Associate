# Dental Clinic Automation - Solution Design

A professional, interactive web presentation showcasing the automation solution for reducing missed calls and no-shows at a 3-chair dental clinic.

## 🚀 Quick Deploy to Vercel

1. **Install Vercel CLI** (if not already installed):
   ```bash
   npm i -g vercel
   ```

2. **Deploy**:
   ```bash
   vercel
   ```
   
   Or simply drag and drop the folder to [vercel.com](https://vercel.com)

3. **Get your link**: Vercel will provide a live URL instantly (e.g., `your-project.vercel.app`)

## 📁 Files Structure


## ✨ Features

- **Interactive Tabs**: Problem scoping with Current State, Pain Points, and Goals
- **Workflow Diagrams**: Three detailed n8n workflow visualizations
- **Metrics Dashboard**: Before/After toggle showing expected ROI
- **Timeline View**: Week-by-week deployment plan
- **Risk Mitigation**: Comprehensive risk analysis
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Smooth Animations**: Professional fade-in and hover effects

## 🎨 Design Principles

- **Clean & Professional**: Modern UI with careful attention to spacing and typography
- **Content-First**: Design supports the story, not the other way around
- **Accessible**: Clear navigation, readable fonts, good contrast
- **Fast Loading**: Vanilla JS, no heavy frameworks
- **Mobile-Friendly**: Responsive design for all screen sizes

## 📝 Content Sections

1. **Hero**: Problem statement and pilot overview
2. **Problem Scoping**: Current state, pain points, goals
3. **Solution Design**: Architecture and component breakdown
4. **Technical Implementation**: Real-world n8n workflows
5. **Deployment Plan**: Week-by-week timeline
6. **Metrics & ROI**: Expected outcomes and business impact
7. **Risk Mitigation**: Proactive approach to challenges

## 🔧 Customization

All content is in `index.html`. To modify:
- Text content: Edit directly in HTML
- Colors: Update CSS variables in `styles.css` (`:root` section)
- Sections: Add/remove sections following the existing structure
